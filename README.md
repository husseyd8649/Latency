# Latency

Uptime monitoring built for solo devs and small teams. HTTP, TCP, and SSL checks with public status pages and HMAC-signed webhooks.

## Stack

Next.js 16 · React 19 · Prisma 6 · PostgreSQL · Auth.js v5 · Tailwind CSS v4 · Recharts · Render

## Local development

```bash
npm install
cp .env.example .env
# Fill in .env with your values
npm run dev
